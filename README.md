This project designs a database for a DJ's music library. We decided to focus on Artists, Songs, Albums, and Genres with relevant information that could create playlists of songs and organize a lot of data in a streamlined way.

A challenge was how to decide how to treat genres because artists, songs, and albums each can have many genres and sub-genres. For the purpose of this database, we have decided that these (artists, songs, albums) will have a 1:1 relationship with genres and only allow the primary genre to be recorded.
